# ObsidianKit Deployment Source

This repository is the active GitHub Pages deployment source for [ObsidianKit](https://github.com/amandeavor/ObsidianKit) and the `obsidiankit.me` custom domain.

## Purpose

ObsidianKit is a browser-native toolbox for document, image, media, calculator, and utility workflows. This repository retains the deployment configuration required by the currently live site.

## Technology

- React and TypeScript
- Vite and Tailwind CSS
- React Router and Zustand
- Browser-based document and media libraries
- GitHub Pages deployment workflow

## Local development

```bash
npm install
npm run dev
```

## Quality commands

```bash
npm run lint
npm test
npm run build
```

## Important deployment note

Do not archive, rename, or remove this repository until the `obsidiankit.me` domain and GitHub Pages workflow have been migrated and verified against the canonical ObsidianKit repository.
